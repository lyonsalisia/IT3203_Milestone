References & Learning Resources

The following documentation, standards organizations, and educational guides were referenced while developing this project:

  • MDN Web Docs (Mozilla): https://developer.mozilla.org/ — Comprehensive technical documentation for HTML5, CSS3, and JavaScript web standards.
  • W3C (World Wide Web Consortium): https://www.w3.org/ — International standards organization responsible for developing web accessibility and markup specifications.
  • W3Schools Online Web Tutorials: https://www.w3schools.com/ — Interactive reference guides and code examples for front-end web development.
  • CSS-Tricks (Complete Guide to Flexbox): https://css-tricks.com/snippets/css/a-guide-to-flexbox/ — Visual reference guide for building responsive navigation and container layouts with CSS Flexbox.
