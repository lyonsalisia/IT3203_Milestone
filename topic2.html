Topic 2: CSS3 Styling & Responsive Layout

CSS (Cascading Style Sheets) controls the visual presentation, layout, typography, and responsiveness of HTML documents across different screen sizes and devices.

Modern CSS Layout Systems

Modern web interfaces rely on flexible layout models rather than rigid positioning to adapt seamlessly between desktop monitors and mobile screens:

  • Flexbox (Flexible Box Layout): Ideal for one-dimensional layouts, such as aligning navigation bar items horizontally or centering elements inside a container.
  • CSS Grid: Designed for two-dimensional layouts, allowing developers to manage rows and columns simultaneously for complex page structures.
  • Media Queries: Conditional CSS rules (@media) that apply specific styles when a viewport reaches a defined width threshold.

CSS Selector Specificity Hierarchy

When multiple CSS rules target the same element, browsers determine which style takes priority based on selector specificity:

  1. Inline Styles: Applied directly inside an HTML tag's style attribute (highest priority).
  2. ID Selectors (#id): Targets a single unique element on the page.
  3. Class Selectors (.class): Targets groups of elements sharing the same class name.
  4. Element Selectors (tag): Targets all instances of a standard HTML tag globally (lowest priority).
